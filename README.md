# 🌌 Aether-ML: Modular Edge AI Framework

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![Field: Space & Industrial AI](https://img.shields.io/badge/Field-Space%20%26%20Industrial%20AI-red.svg)](https://www.combitech.se)

**Aether-ML** is a lightweight, high-performance modular framework designed for deploying advanced AI models to high-reliability edge environments. Built with the constraints of **Industrial Autonomy** and **Space Operations** in mind, it provides a structured way to handle real-time sensor streams and run inference with minimal latency.

Developed by **Henrik Karlsson** (Tech Lead AI @ Combitech Sverige, fmr NASA JPL).

---

## 🚀 Key Features

- **Modular AI Engine:** Easily register and swap models for different mission requirements.
- **Lightweight Inference:** Optimized for resource-constrained Edge AI hardware.
- **Space-Grade Reliability:** Designed for autonomous telemetry analysis and subsystem monitoring.
- **Statistical Baselines:** Built-in tools for establishing 'Normal Ops' baselines for anomaly detection.

---

## 🏗️ Architecture

```text
Aether-ML/
├── core/               # Central processing engine & stream handlers
├── models/             # Specialized AI models (Anomaly Detection, etc.)
├── examples/           # Real-world mission simulation scripts
├── configs/            # Hardware & mission-specific parameters
└── tests/              # Validation suite for high-reliability ops
```

## 🛠️ Quick Start

### Installation

```bash
git clone https://github.com/HenrikKarlsson-AI/Aether-ML.git
cd Aether-ML
pip install -r requirements.txt
```

### Running a Satellite Simulation

Experience Aether-ML in action by simulating a satellite power subsystem monitoring mission:

```bash
python examples/satellite_ops.py
```
